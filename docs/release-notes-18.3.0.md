# RuleDesk 18.3.0

## What's new

- **Exact tag search** — searching for a tag matches the full name, including underscores and hyphens, so close variants no longer collide.
- **Stable playlist pages** — scrolling or paging through playlists no longer shows the same post twice.

## Fixed

- **Backup without UI freezes** — creating a backup no longer locks up the window while it runs.
- **Fast sync cancel** — stopping a sync responds quickly instead of hanging until the current batch finishes.
- **Consistent unread counters** — unread badges and counts stay in sync across the app after sync and browse.

## Important

On first launch after this update, RuleDesk may automatically update your database and search index. On large libraries this can take a while — let the app finish starting before you quit.
