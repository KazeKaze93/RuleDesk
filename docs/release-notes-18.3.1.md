# RuleDesk 18.3.1

## What's new

- **Post metadata on first open** — Artist, Character, and Copyright fill in when you open a post the first time, without closing and reopening.
- **Clearer docs** — backup retention, cache TTL, download limits, and related settings now match what the app actually does.

## Fixed

- Internal IPC validation is inventoried and unified on one registration path, so channel contracts stay consistent.

## Important

No database upgrade is required for this patch. If you still see empty Post Metadata on first open, fully quit RuleDesk and start it again once.
