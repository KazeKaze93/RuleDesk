## Ключи API

### Запрос ключа API

**URL:** https://rule34.xxx/index.php?page=account&s=options

Перейдите на страницу настроек аккаунта, чтобы запросить ключ API. Вы получите:

- `user_id`: Ваш ID пользователя
- `api_key`: Ваш ключ API для аутентификации

### Ограничения API

Ограничения API могут быть изменены в любое время без предварительного уведомления. Если вашему приложению требуются более высокие лимиты, вы можете запросить неограниченный ключ. Это применимо только для крупных публичных проектов.

**Запрос более высоких лимитов:**

- Для срочных запросов от крупных сайтов/приложений: Создайте тикет в Discord или отправьте сообщение администрации сайта
- Форум для связи с администрацией: https://rule34.xxx/index.php?page=forum&s=view&id=4240

**Важно:** Rule34.xxx оставляет за собой право отключить или отклонить любой ключ API по своему усмотрению.

## Условия использования API

При использовании API Rule34.xxx или при размещении контента с их CDN, вы должны соблюдать следующие условия:

1.  **Без рекламы и платного доступа:** Вы не должны отображать рекламу или использовать платный доступ. Это относится ко всем ботам, приложениям и веб-сайтам, использующим API или контент CDN.

2.  **Правило одного ключа API:** Не используйте и не запрашивайте более одного ключа API. Использование нескольких ключей приведёт к блокировке вашего ключа или аккаунта.

3.  **Блокировка ключа:** Нарушение этих условий может привести к немедленной блокировке вашего ключа API или аккаунта.

## Конечные точки

### Публикации

#### Список публикаций

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=post&q=index`

**Метод:** GET

**Параметры:**

| Параметр | Тип       | Описание                         | Ограничения                                                                      |
| :------- | :-------- | :------------------------------- | :------------------------------------------------------------------------------- |
| `limit`  | integer   | Количество публикаций для получения | Жёсткий лимит: 1000 публикаций за запрос                                         |
| `pid`    | integer   | Номер страницы                   | -                                                                                |
| `tags`   | string    | Комбинация тегов для поиска      | Любая комбинация тегов, работающая на сайте, включая мета-теги                   |
| `cid`    | integer   | ID изменения публикации          | Unix-метка времени (могут быть дубликаты при одновременном обновлении)           |
| `id`     | integer   | ID публикации                    | -                                                                                |
| `json`   | integer   | Формат ответа                    | Установите `1` для JSON, опустите для XML                                        |

**Примечания:**

- Формат ответа по умолчанию — XML, если не указано `json=1`
- Комбинации тегов следуют тем же правилам, что и поиск на сайте
- См. шпаргалку для получения информации о мета-тегах

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&tags=tag1+tag2&limit=100&json=1
```

### Удалённые изображения

#### Список удалённых изображений

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&deleted=show`

**Метод:** GET

**Параметры:**

| Параметр  | Тип       | Описание        | Ограничения                          |
| :-------- | :-------- | :-------------- | :----------------------------------- |
| `last_id` | integer   | Числовое значение | Возвращает всё, что выше этого числа |

**Примечания:**

- Эта конечная точка требует параметр `deleted=show` в URL
- Используйте `last_id` для постраничной навигации по удалённым изображениям

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&deleted=show&last_id=12345
```

### Комментарии

#### Список комментариев

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=comment&q=index`

**Метод:** GET

**Параметры:**

| Параметр  | Тип       | Описание          | Ограничения                                       |
| :-------- | :-------- | :---------------- | :------------------------------------------------ |
| `post_id` | integer   | ID публикации     | ID публикации, для которой нужно получить комментарии |

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=comment&q=index&post_id=123456
```

### Теги

#### Список тегов

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=tag&q=index`

**Метод:** GET

**Параметры:**

| Параметр | Тип       | Описание                    | Ограничения                                                    |
| :------- | :-------- | :-------------------------- | :------------------------------------------------------------- |
| `id`     | integer   | ID тега в базе данных       | Полезно для получения конкретного тега, если вы уже знаете его ID |
| `limit`  | integer   | Количество тегов для получения | Лимит по умолчанию: 100 тегов за запрос                        |

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=tag&q=index&limit=500
```

### Автодополнение

#### Автодополнение тегов

**URL:** `https://api.rule34.xxx/autocomplete.php?q=`

**Метод:** GET

**Параметры:**

| Параметр | Тип    | Описание        | Ограничения                          |
| :------- | :----- | :-------------- | :----------------------------------- |
| `q`      | string | Поисковый запрос | Введите любую букву или неполный тег |

**Примечания:**

- Это неофициальная конечная точка, но она доступна для использования
- Некоторые реализации могут использовать автодополнение с основного сайта; используйте вместо него эту конечную точку
- Возвращает предложения на основе частичного ввода тега

**Пример:**

```
https://api.rule34.xxx/autocomplete.php?q=char
```

## Рекомендации и меры предосторожности

### Ограничение частоты запросов

- Реализуйте экспоненциальную задержку при ошибках ограничения частоты запросов
- Соблюдайте ограничения API и избегайте агрессивного опроса
- Контролируйте частоту запросов, чтобы предотвратить блокировку IP или ключа
- Рассмотрите кэширование ответов для уменьшения количества вызовов API

### Кэширование

- Кэшируйте списки тегов и результаты автодополнения (они меняются нечасто)
- Кэшируйте метаданные публикаций для уменьшения избыточных запросов
- Реализуйте соответствующие стратегии инвалидации кэша
- Учитывайте размер кэша и использование памяти

### Соответствие условиям использования

- **Никогда не отображайте рекламу** при использовании API или размещении контента CDN
- **Никогда не вводите платный доступ** для контента, доступ к которому осуществляется через API
- **Используйте только один ключ API** на приложение или проект
- Ознакомьтесь и соблюдайте все требования ToS перед развёртыванием

### Управление ключами

- Храните ключи API безопасно (используйте безопасное хранилище Electron или аналогичное решение)
- Никогда не фиксируйте ключи API в системе контроля версий
- Отслеживайте уведомления о блокировке ключей
- Разработайте план на случай отзыва ключа

### Обработка ошибок

- Реализуйте надлежащую обработку ошибок при сбоях сети
- Изящно обрабатывайте ответы об ограничении частоты запросов
- Регистрируйте ошибки для отладки, не раскрывая конфиденциальную информацию
- Предоставляйте удобные для пользователя сообщения об ошибках

### Вопросы производительности

- Используйте пагинацию (параметр `pid`) для больших наборов результатов
- Соблюдайте лимит в 1000 публикаций за запрос
- Рассмотрите параллельные запросы для независимых данных (с учётом ограничения частоты запросов)
- Оптимизируйте запросы тегов для уменьшения размера ответа

### Безопасность

- Проверяйте все пользовательские вводы перед формированием запросов к API
- Санитизируйте строки тегов для предотвращения инъекционных атак
- Используйте HTTPS для всех запросов к API
- Реализуйте обработку тайм-аутов запросов

### Рекомендации по разработке

- Сначала тестируйте с небольшими лимитами, прежде чем масштабировать
- Отслеживайте время ответа API и соответствующим образом настраивайте интервалы опроса
- Реализуйте логику повторных попыток с экспоненциальной задержкой
- Используйте формат JSON (`json=1`) для упрощения парсинга в современных приложениях
- Документируйте шаблоны использования API для устранения неполадок
