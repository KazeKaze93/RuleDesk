## Ключи API

### Запрос ключа API

**URL:** https://rule34.xxx/index.php?page=account&s=options

Перейдите на страницу настроек учетной записи, чтобы запросить ключ API. Вы получите:

- `user_id`: Ваш ID пользователя
- `api_key`: Ваш ключ API для аутентификации

### Ограничения API

Ограничения API могут быть изменены в любое время без предварительного уведомления. Если вашему приложению требуются более высокие лимиты, вы можете запросить неограниченный ключ. Это применимо только для крупных публичных проектов.

**Запрос более высоких лимитов:**

- Для срочных запросов от крупных сайтов/приложений: Создайте заявку в Discord или отправьте электронное письмо сотрудникам сайта
- Форум для связи с сотрудниками: https://rule34.xxx/index.php?page=forum&s=view&id=4240

**Важно:** Rule34.xxx оставляет за собой право отключать или отклонять любой ключ API по своему усмотрению.

## Условия использования API

При использовании API Rule34.xxx или распространении контента с их CDN, вы должны соблюдать следующие условия:

1.  **Без рекламы и платного доступа:** Вы не должны отображать рекламу или использовать платный доступ. Это относится ко всем ботам, приложениям и веб-сайтам, использующим API или контент CDN.

2.  **Правило одного ключа API:** Не используйте и не запрашивайте более одного ключа API. Использование нескольких ключей приведет к приостановке действия вашего ключа или учетной записи.

3.  **Приостановка действия ключа:** Нарушение этих условий может привести к немедленной приостановке действия вашего ключа API или учетной записи.

## Конечные точки

### Публикации

#### Список публикаций

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=post&q=index`

**Method:** GET

**Параметры:**

| Параметр | Тип   | Описание                       | Ограничения                                                        |
| -------- | ----- | ------------------------------ | ------------------------------------------------------------------ |
| `limit`  | число | Количество публикаций для извлечения | Жесткое ограничение: 1000 публикаций на запрос                     |
| `pid`    | число | Номер страницы                 | -                                                                  |
| `tags`   | строка | Комбинация тегов для поиска    | Любая комбинация тегов, работающая на сайте, включая мета-теги |
| `cid`    | число | Change ID публикации           | Метка времени Unix (могут быть дубликаты при одновременном обновлении) |
| `id`     | число | ID публикации                  | -                                                                  |
| `json`   | число | Формат ответа                  | Установите значение `1` для JSON, опустите для XML                 |

**Примечания:**

- Формат ответа по умолчанию — XML, если не указано `json=1`
- Комбинации тегов следуют тем же правилам, что и поиск на сайте
- См. шпаргалку для получения информации о мета-тегах

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&tags=tag1+tag2&limit=100&json=1
```

### Удаленные изображения

#### Список удаленных изображений

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&deleted=show`

**Method:** GET

**Параметры:**

| Параметр  | Тип   | Описание        | Ограничения                          |
| --------- | ----- | --------------- | ------------------------------------ |
| `last_id` | число | Числовое значение | Возвращает все элементы выше этого числа |

**Примечания:**

- Эта конечная точка требует параметр `deleted=show` в URL
- Используйте `last_id` для пагинации удаленных изображений

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=post&q=index&deleted=show&last_id=12345
```

### Комментарии

#### Список комментариев

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=comment&q=index`

**Method:** GET

**Параметры:**

| Параметр  | Тип   | Описание       | Ограничения                                 |
| --------- | ----- | -------------- | ------------------------------------------- |
| `post_id` | число | ID публикации | ID публикации, для которой извлекаются комментарии |

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=comment&q=index&post_id=123456
```

### Теги

#### Список тегов

**URL:** `https://api.rule34.xxx/index.php?page=dapi&s=tag&q=index`

**Method:** GET

**Параметры:**

| Параметр | Тип   | Описание                 | Ограничения                                                  |
| -------- | ----- | ------------------------ | ------------------------------------------------------------ |
| `id`     | число | ID тега в базе данных    | Полезно для извлечения конкретного тега, если вы уже знаете ID |
| `limit`  | число | Количество тегов для извлечения | Ограничение по умолчанию: 100 тегов на запрос                |

**Пример:**

```
https://api.rule34.xxx/index.php?page=dapi&s=tag&q=index&limit=500
```

### Автозаполнение

#### Автозаполнение тегов

**URL:** `https://api.rule34.xxx/autocomplete.php?q=`

**Method:** GET

**Параметры:**

| Параметр | Тип   | Описание       | Ограничения                        |
| -------- | ----- | -------------- | ---------------------------------- |
| `q`      | строка | Поисковый запрос | Введите любую букву или неполный тег |

**Примечания:**

- Это неофициальная конечная точка, но ее можно использовать
- Некоторые реализации могут использовать автозаполнение с основного сайта; используйте вместо этого эту конечную точку
- Возвращает предложения на основе частичного ввода тега

**Пример:**

```
https://api.rule34.xxx/autocomplete.php?q=char
```

## Рекомендации и меры предосторожности

### Ограничение частоты запросов

- Реализуйте экспоненциальную задержку при ошибках ограничения частоты запросов
- Соблюдайте ограничения API и избегайте агрессивного опроса
- Отслеживайте частоту ваших запросов, чтобы предотвратить блокировку IP или ключа
- Рассмотрите возможность кэширования ответов для уменьшения количества вызовов API

### Кэширование

- Кэшируйте списки тегов и результаты автозаполнения (они меняются нечасто)
- Кэшируйте метаданные публикаций для уменьшения избыточных запросов
- Реализуйте соответствующие стратегии инвалидации кэша
- Помните о размере кэша и использовании памяти

### Соблюдение Условий использования

- **Никогда не отображайте рекламу** при использовании API или распространении контента CDN
- **Никогда не используйте платный доступ** для контента, доступ к которому осуществляется через API
- **Используйте только один ключ API** для каждого приложения или проекта
- Ознакомьтесь и соблюдайте все требования ToS перед развертыванием

### Управление ключами

- Надежно храните ключи API (используйте безопасное хранилище Electron или аналогичное)
- Никогда не коммитьте ключи API в систему контроля версий
- Отслеживайте уведомления о приостановке действия ключа
- Имейте план на случай отзыва ключа

### Обработка ошибок

- Реализуйте надлежащую обработку ошибок для сетевых сбоев
- Изящно обрабатывайте ответы об ограничении частоты запросов
- Регистрируйте ошибки для отладки, не раскрывая конфиденциальную информацию
- Предоставляйте удобные для пользователя сообщения об ошибках

### Вопросы производительности

- Используйте пагинацию (параметр `pid`) для больших наборов результатов
- Соблюдайте ограничение в 1000 публикаций на запрос
- Рассмотрите возможность параллельных запросов для независимых данных (с учетом ограничения частоты)
- Оптимизируйте запросы тегов для уменьшения размера ответа

### Безопасность

- Проверяйте все пользовательские данные перед формированием запросов API
- Санитизируйте строки тегов, чтобы предотвратить инъекционные атаки
- Используйте HTTPS для всех запросов API
- Реализуйте обработку тайм-аутов запросов

### Рекомендации по разработке

- Сначала тестируйте с небольшими лимитами, прежде чем масштабировать
- Отслеживайте время ответа API и соответствующим образом корректируйте интервалы опроса
- Реализуйте логику повторных попыток с экспоненциальной задержкой
- Используйте формат JSON (`json=1`) для более простого парсинга в современных приложениях
- Документируйте свои шаблоны использования API для устранения неполадок
