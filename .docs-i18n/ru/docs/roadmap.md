## 🧭 Переработка навигации и UX

### Боковая навигация

Реализовать постоянную боковую панель с основными разделами навигации:

- **Обновления** - Лента подписок (новые посты из отслеживаемых источников)
- **Просмотр** - Все посты с расширенной фильтрацией
- **Избранное** - Избранное аккаунта, синхронизированное с booru
- **Отслеживаемые** - Управление artist и tag
- **Настройки** - Конфигурация приложения

### Глобальная верхняя панель

Унифицированная верхняя панель на всех страницах контента:

- **Панель поиска** - Быстрый поиск по постам, tag, artist
- **Панель фильтров** - Фильтры по рейтингу, типу медиа, tag, диапазону дат
- **Элементы управления сортировкой** - Сортировка по дате добавления, дате публикации, рейтингу
- **Переключение вида** - Опции макета сетки, списка, masonry
- **Статус синхронизации** - Индикатор синхронизации в реальном времени с меткой времени последней синхронизации

### Улучшение Просмотрщика

Улучшенный полноэкранный просмотр:

- **Автоскрытие панелей** - Верхняя и нижняя панели скрываются после бездействия
- **Панель Tag** - Выдвижная панель справа с кликабельными tag
  - Нажмите на tag, чтобы добавить фильтр (`+tag`)
  - Нажмите правой кнопкой мыши или клавишей-модификатором, чтобы исключить (`-tag`)
  - Визуальные индикаторы активных фильтров
- **Подсказки** - Горячие клавиши и подсказки по действиям
- **Горячие клавиши:**
  - `Esc` - Закрыть просмотрщик
  - `←/→` - Перемещение между постами
  - `F` - Переключить избранное
  - `V` - Отметить как просмотренное
  - `T` - Переключить панель tag

### Наложения на карточки галереи

Карточки постов с информативными наложениями:

- **Значок "Просмотрено"** - Индикатор для просмотренных постов
- **Значок "Избранное"** - Иконка звезды для избранных постов
- **Значок рейтинга** - Визуальный индикатор (Безопасный/Сомнительный/Явный)
- **Значок типа медиа** - Иконка для изображений/видео

### Прогрессивная загрузка изображений

Оптимизированная стратегия загрузки:

- **URL превью** - Размытое превью низкого разрешения (мгновенное отображение в галерее)
- **URL образца** - Образец среднего разрешения (загружается в галерее)
- **URL файла** - Оригинал полного разрешения (загружается только в просмотрщике)

## 🛡️ Безопасность и надёжность (Укрепление)

### Безопасность API-ключа

Улучшенная безопасность для учётных данных API:

- **Изоляция Renderer** - Renderer process никогда не получает необработанный API-ключ
- **Безопасное хранение** - Использование API `safeStorage` Electron (Диспетчер учётных данных Windows, Связка ключей macOS, Linux libsecret)
- **Политика AES-GCM** - Шифрование API-ключей в покое с помощью AES-GCM шифрования
- **Модель угроз** - Украденный файл базы данных не раскрывает API-ключ в открытом виде

**Статус:** ✅ **ВЫПОЛНЕНО:** API-ключи зашифрованы в покое, расшифровка только в Main Process.

### Резервное копирование и целостность базы данных

Комплексная защита базы данных:

- **Система резервного копирования** - Ручное и автоматическое резервное копирование перед обслуживанием
- **Процесс восстановления** - Восстановление из резервной копии с автоматическим перезапуском
- **Проверка целостности** - Выполнение `PRAGMA integrity_check` и отображение результатов
- **Политика хранения** - Хранение последних N резервных копий, автоматическая очистка старых резервных копий

**Статус:** ✅ **Фаза 1 ВЫПОЛНЕНА:** Реализовано ручное резервное копирование/восстановление. В будущем: Автоматическое резервное копирование, UI проверки целостности, политика хранения.

### Автоматическое обслуживание

Неблокирующее обслуживание базы данных:

- **Очередь обслуживания** - Все операции обслуживания выполняются последовательно через очередь на основе Promise (`maintenance-queue.ts`)
- **Неблокирующее** - Операции обслуживания не замораживают UI (операции асинхронны)
- **События прогресса** - Обновления прогресса в реальном времени для длительных операций
- **Запланированные запуски** - Автоматическое обслуживание при запуске или через периодические интервалы (запланировано)

**Статус:** ✅ **ВЫПОЛНЕНО:** Операции обслуживания базы данных используют последовательную очередь для предотвращения состояний гонки. В будущем: Запланированные запуски обслуживания.
