## 🧭 Обновление навигации и UX

### Навигация в боковой панели

Реализовать постоянную боковую панель с основными разделами навигации:

- **Обновления** - Лента подписок (новые посты из отслеживаемых источников)
- **Просмотр** - Просмотр всех постов с расширенной фильтрацией
- **Избранное** - Избранное аккаунта, синхронизированное с booru
- **Отслеживаемые** - Управление художниками и Tag'ами
- **Настройки** - Конфигурация приложения

### Глобальная верхняя панель

Единая верхняя панель на всех страницах контента:

- **Поиск** - Быстрый поиск по постам, Tag'ам, художникам
- **Панель фильтров** - Фильтры по рейтингу, типу медиа, Tag'ам, диапазону дат
- **Элементы управления сортировкой** - Сортировка по дате добавления, дате публикации, рейтингу
- **Переключатель вида** - Варианты макета сетки, списка, "каменной кладки"
- **Статус синхронизации** - Индикатор синхронизации в реальном времени с временной меткой последней синхронизации

### Улучшение просмотрщика

Улучшенный полноэкранный режим просмотра:

- **Автоматическое скрытие панелей** - Верхняя и нижняя панели скрываются после периода бездействия
- **Лист Tag'ов** - Выдвижная панель справа с кликабельными Tag'ами
  - Нажмите на Tag, чтобы добавить фильтр (`+tag`)
  - Правый клик или клавиша-модификатор для исключения (`-tag`)
  - Визуальные индикаторы активных фильтров
- **Подсказки** - Горячие клавиши и подсказки действий
- **Горячие клавиши:**
  - `Esc` - Закрыть просмотрщик
  - `←/→` - Навигация между постами
  - `F` - Переключить избранное
  - `V` - Отметить как просмотренное
  - `T` - Переключить панель Tag'ов

### Наложения на карточки галереи

Карточки постов с информативными наложениями:

- **Значок просмотренного** - Индикатор для просмотренных постов
- **Значок избранного** - Иконка звезды для избранных постов
- **Значок рейтинга** - Визуальный индикатор (Безопасно/Сомнительно/Откровенно)
- **Значок типа медиа** - Иконка для изображений/видео

### Прогрессивная загрузка изображений

Оптимизированная стратегия загрузки:

- **URL предпросмотра** - Размытый предпросмотр низкого разрешения (мгновенное отображение в галерее)
- **URL образца** - Образец среднего разрешения (загружается в галерее)
- **URL файла** - Оригинал полного разрешения (загружается только в просмотрщике)

## 🛡️ Безопасность и надежность (Укрепление)

### Безопасность API-ключей

Улучшенная безопасность для учетных данных API:

- **Изоляция Renderer'а** - Renderer Process никогда не получает необработанный API-ключ
- **Безопасное хранение** - Использование `safeStorage` API Electron (Диспетчер учетных данных Windows, Связка ключей macOS, Linux libsecret)
- **Политика AES-GCM** - Шифрование API-ключей в состоянии покоя с помощью AES-GCM
- **Модель угроз** - Украденный файл базы данных не раскрывает API-ключ в открытом виде

**Статус:** ✅ **ЗАВЕРШЕНО:** API-ключи зашифрованы в состоянии покоя, расшифровка только в Main Process.

### Резервное копирование и целостность базы данных

Комплексная защита базы данных:

- **Система резервного копирования** - Ручное и автоматическое резервное копирование перед обслуживанием
- **Процесс восстановления** - Восстановление из резервной копии с автоматическим перезапуском
- **Проверка целостности** - Выполнение `PRAGMA integrity_check` и отображение результатов
- **Политика хранения** - Хранение N последних резервных копий, автоматическая очистка старых резервных копий

**Статус:** ✅ **Фаза 1 ЗАВЕРШЕНА:** Реализовано ручное резервное копирование/восстановление. Будущее: Автоматическое резервное копирование, UI проверки целостности, политика хранения.

### Автоматическое обслуживание

Неблокирующее обслуживание базы данных:

- **Очередь обслуживания** - Все операции обслуживания выполняются последовательно через очередь на основе Promise (`maintenance-queue.ts`)
- **Неблокирующий режим** - Операции обслуживания не замораживают UI (операции асинхронны)
- **События прогресса** - Обновления прогресса в реальном времени для длительных операций
- **Запланированные запуски** - Автоматическое обслуживание при запуске или через периодические интервалы (запланировано)

**Статус:** ✅ **ЗАВЕРШЕНО:** Операции обслуживания базы данных используют последовательную очередь для предотвращения состояний гонки. Будущее: Запланированные запуски обслуживания.
