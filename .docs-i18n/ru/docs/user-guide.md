## Установка

### Windows

1.  Загрузите установщик со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Запустите установщик (файл `.exe`)
3.  Следуйте инструкциям мастера установки
4.  RuleDesk будет установлен в папку Program Files

**Портативная версия (опционально):**

Если вы предпочитаете портативную версию, не требующую установки:

1.  Загрузите портативный файл `.exe`
2.  Распакуйте его в любую папку
3.  Запустите `RuleDesk.exe` напрямую
4.  Ваши данные будут храниться в папке `data/` рядом с исполняемым файлом

### macOS

1.  Загрузите файл `.dmg` со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Откройте файл `.dmg`
3.  Перетащите RuleDesk в папку «Программы»
4.  Откройте RuleDesk из папки «Программы» (возможно, потребуется разрешить его в «Системных настройках» > «Безопасность»)

### Linux

1.  Загрузите файл `.AppImage` со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Сделайте его исполняемым: `chmod +x RuleDesk-*.AppImage`
3.  Запустите: `./RuleDesk-*.AppImage`

## Первый запуск

При первом открытии RuleDesk вы увидите экран **Onboarding**. Здесь вы введете свои учетные данные API.

### Что такое учетные данные API?

RuleDesk требуются учетные данные вашей учетной записи Rule34.xxx для получения постов. Эти данные включают:

-   **User ID** — Идентификатор вашей учетной записи
-   **API Key** — Специальный ключ, который позволяет RuleDesk получать доступ к API

**Не беспокойтесь** — эти данные зашифрованы и надежно хранятся на вашем компьютере. Они никогда не отправляются никуда, кроме API Rule34.xxx.

---

## Получение учетных данных API

1.  **Откройте свой веб-браузер** и перейдите по адресу:

    ```
    https://rule34.xxx/index.php?page=account&s=options
    ```

2.  **Войдите** в свою учетную запись Rule34.xxx (если вы еще не вошли)

3.  **Прокрутите вниз** до раздела "API Access"

4.  **Скопируйте свои учетные данные:**

    -   **User ID** — Число рядом с "User ID"
    -   **API Key** — Длинная строка рядом с "API Key"

5.  **Вставьте их в RuleDesk:**

    -   Вы можете вставить полный URL-адрес со страницы учетной записи, и RuleDesk автоматически извлечет учетные данные
    -   Или введите их вручную в соответствующие поля

6.  **Нажмите "Save and Login"**

Вот и все! Теперь вы готовы использовать RuleDesk.

## Основные сведения об использовании

### Добавление отслеживаемых авторов

**Что такое "отслеживание"?** Отслеживание означает, что RuleDesk будет автоматически проверять наличие новых постов от определенных авторов или Tag.

**Как добавить автора:**

1.  Нажмите кнопку **"Tracked"** на боковой панели (левая часть экрана)

2.  Нажмите кнопку **"Add Source"** (вверху справа, со значком +)

3.  Заполните форму:

    -   **Name** — Понятное имя для этого автора (например, "My Favorite Artist")
    -   **Tag** — Tag или имя пользователя для отслеживания (например, "artist_name" или "tag_name")
    -   **Type** — Выберите:
        -   **Tag** — Отслеживать посты с этим Tag
        -   **Uploader** — Отслеживать посты, загруженные этим пользователем
        -   **Query** — Отслеживать посты, соответствующие пользовательскому запросу
    -   **Source** — Выберите, какой сайт использовать (Rule34.xxx или Gelbooru)

4.  Нажмите **"Add"**

Автор появится в вашем списке отслеживаемых!

**Совет:** Вы можете использовать поле поиска для нахождения Tag. Введите несколько букв, и RuleDesk предложит соответствующие Tag.

### Синхронизация постов

**Что такое синхронизация?** Это когда RuleDesk загружает новые посты с веб-сайта и сохраняет их в вашу локальную базу данных.

**Как синхронизировать:**

1.  Нажмите кнопку **"Sync All"** на боковой панели (в верхней части боковой панели, со значком обновления)

2.  Дождитесь завершения синхронизации. Вы увидите сообщения о ходе выполнения, например:

    -   "Синхронизация artist_name..."
    -   "Найдено 15 новых постов"
    -   "Синхронизация завершена!"

3.  Синхронизация выполняется в фоновом режиме, поэтому вы можете продолжать использовать приложение во время синхронизации

**Автоматическая синхронизация:**

Вы можете включить автоматическую синхронизацию в Настройках:

-   **Auto-sync on startup** — Синхронизация при запуске приложения
-   **Periodic sync** — Синхронизация каждые X минут во время работы приложения

**Как включить:**

1.  Перейдите в **Настройки** (боковая панель)
2.  Прокрутите до **Настройки синхронизации**
3.  Включите **"Auto-sync on Startup"**
4.  Установите **"Periodic Sync Interval"** (например, 30 минут)

### Просмотр постов

**Чтобы просмотреть посты отслеживаемого автора:**

1.  Перейдите на страницу **"Tracked"**
2.  Нажмите на карточку автора
3.  Вы увидите галерею всех его постов

**В галерее:**

-   **Прокрутите вниз**, чтобы увидеть больше постов (они загружаются автоматически)
-   **Нажмите на пост**, чтобы открыть его в полноэкранном просмотрщике
-   **Используйте стрелки** (← →) для навигации между постами
-   **Нажмите Esc**, чтобы закрыть просмотрщик

**Информация о посте:**

На каждой карточке поста отображается:

-   Изображение-превью
-   Значок рейтинга (Safe/Questionable/Explicit)
-   Значок типа медиа (изображение или видео)
-   Индикатор просмотра (если вы уже видели его)
-   Звезда избранного (если вы добавили его в избранное)

## Функции

### Поиск

**Поиск авторов локально:**

1.  Перейдите на страницу **"Tracked"**
2.  Используйте поле поиска вверху
3.  Введите имя автора или Tag
4.  Результаты появляются по мере ввода

**Поиск Tag удаленно:**

1.  При добавлении автора начните вводить текст в поле "Tag"
2.  RuleDesk будет искать в базе данных Tag веб-сайта
3.  Выберите Tag из предложенных

**Поиск постов:**

1.  Перейдите на страницу **"Browse"** (когда будет реализовано)
2.  Используйте строку поиска в верхней панели
3.  Введите Tag или ключевые слова
4.  Результаты будут фильтроваться автоматически

### Избранное

**Что такое избранное?** Отмечайте посты, которые вам нравятся, чтобы легко найти их позже.

**Как добавить пост в избранное:**

1.  Откройте пост в просмотрщике (нажмите на него)
2.  Нажмите **значок звезды** (⭐) в элементах управления просмотрщика
3.  Или нажмите **F** на клавиатуре

**Просмотр избранного:**

1.  Нажмите **"Favorites"** на боковой панели
2.  Вы увидите все свои посты, добавленные в избранное

**Удалить из избранного:**

1.  Откройте пост
2.  Нажмите значок звезды снова (или нажмите F)
3.  Звезда станет серой (удалено из избранного)

### Загрузка постов

**Загрузка одного поста:**

1.  Откройте пост в просмотрщике
2.  Нажмите кнопку **"Download Original"** (значок загрузки)
3.  Выберите, куда сохранить файл
4.  Нажмите **"Save"**

Начнется загрузка, и вы увидите индикатор прогресса.

**После загрузки:**

-   Нажмите **"Open in Folder"**, чтобы увидеть загруженный файл
-   Файл будет сохранен с исходным именем

**Примечание:** Загрузки сохраняются в выбранное вами место, а не в кеш приложения.

### Фильтры и сортировка

**Фильтрация постов по рейтингу:**

1.  В любом представлении галереи посмотрите на верхнюю панель
2.  Нажмите кнопку **"Filters"**
3.  Выберите рейтинг: **Safe**, **Questionable** или **Explicit**
4.  Галерея обновится, чтобы показать только посты с этим рейтингом

**Фильтрация по типу медиа:**

1.  Нажмите **"Filters"** в верхней панели
2.  Выберите **"Images"** или **"Videos"**
3.  Галерея обновляется автоматически

**Сортировка постов:**

1.  Нажмите выпадающее меню **"Sort"** в верхней панели
2.  Выберите:
    -   **Date Added (Newest)** — Сначала недавно синхронизированные посты
    -   **Date Added (Oldest)** — Сначала самые старые синхронизированные посты
    -   **Posted Date** — Дата исходной публикации поста
    -   **Rating** — Группировка по рейтингу

**Фильтрация по Tag:**

1.  Откройте пост в просмотрщике
2.  Нажмите кнопку **"Tags"** (или **T**), чтобы открыть панель Tag
3.  Нажмите на любой Tag, чтобы добавить его в качестве фильтра
4.  Щелкните правой кнопкой мыши (или удерживайте клавишу-модификатор), чтобы исключить Tag
5.  Галерея обновится, чтобы показать только посты, соответствующие вашим фильтрам

**Сброс фильтров:**

-   Нажмите кнопку **"Clear Filters"** в верхней панели
-   Или вручную удалите фильтры из панели Tag

### Отметка постов как просмотренных

**Зачем отмечать посты как просмотренные?** Это помогает вам отслеживать то, что вы уже видели, чтобы вы могли сосредоточиться на новом контенте.

**Отметить пост как просмотренный:**

1.  Откройте пост в просмотрщике
2.  Нажмите **V** на клавиатуре
3.  Или нажмите кнопку **"Mark as Viewed"**

**Визуальный индикатор:**

-   Просмотренные посты отображают небольшой значок/индикатор на карточке поста
-   Это помогает вам быстро увидеть, что нового

**Отметить все как просмотренные:**

-   Эта функция запланирована для будущих релизов

## Навигация

RuleDesk имеет **боковую панель** слева с основными разделами:

### Разделы боковой панели

-   **Updates** — Просмотр всех новых постов от отслеживаемых авторов (запланировано)
-   **Browse** — Просмотр всех кешированных постов с фильтрами (запланировано)
-   **Favorites** — Ваша коллекция избранных постов
-   **Tracked** — Управление отслеживаемыми авторами и Tag
-   **Settings** — Конфигурация и предпочтения приложения

### Верхняя панель

**Верхняя панель** отображается на страницах с контентом и предоставляет:

-   **Search box** — Поле поиска авторов, Tag или постов
-   **Filters button** — Кнопка открытия панели фильтров
-   **Sort dropdown** — Выпадающее меню сортировки
-   **View toggle** — Переключение между режимами сетки/списка
-   **Sync status** — Просмотр времени последней синхронизации и прогресса

### Сочетания клавиш

**В просмотрщике:**

-   **Esc** — Закрыть просмотрщик
-   **← / →** — Предыдущий/Следующий пост
-   **F** — Переключить избранное
-   **V** — Отметить как просмотренное
-   **T** — Переключить панель Tag

**Глобально:**

-   **Ctrl/Cmd + S** — Синхронизировать все (запланировано)
-   **Ctrl/Cmd + F** — Фокусировка на поиске (запланировано)

## Настройки

Доступ к настройкам осуществляется нажатием **"Settings"** на боковой панели.

### Настройки синхронизации

-   **Auto-sync on Startup** — Автоматическая синхронизация при запуске приложения
-   **Periodic Sync Interval** — Как часто проверять наличие новых постов (например, каждые 30 минут)
-   **Rate Limiting** — Регулировка задержек между запросами к API (расширенные)

### Хранилище и кеш

-   **Cache Limit** — Максимальный размер для кешированных изображений-превью
-   **Clear Cache** — Удалить все кешированные изображения (освобождает место на диске)
-   **Storage Usage** — Посмотреть, сколько места использует приложение

### Безопасность

-   **API Key Storage** — Ваши учетные данные зашифрованы и надежно хранятся
-   **Logout** — Очистить учетные данные и вернуться к онбордингу

### Управление базой данных

-   **Create Backup** — Создать резервную копию вашей базы данных (рекомендуется перед серьезными изменениями)
-   **Restore Backup** — Восстановить из предыдущей резервной копии
-   **Integrity Check** — Проверить базу данных на целостность
-   **Vacuum/Compact** — Оптимизировать размер файла базы данных

**Как создать резервную копию:**

1.  Перейдите в **Настройки**
2.  Прокрутите до **Управление базой данных**
3.  Нажмите **"Create Backup"**
4.  Будет создан файл резервной копии с временной меткой
5.  Расположение файла откроется автоматически

**Как восстановить резервную копию:**

1.  Перейдите в **Настройки** > **Управление базой данных**
2.  Нажмите **"Restore Backup"**
3.  Выберите файл резервной копии
4.  Подтвердите восстановление
5.  Приложение перезапустится автоматически

## Устранение неполадок

### Ошибка "No API credentials"

**Проблема:** Приложение сообщает, что вам нужно ввести учетные данные API.

**Решение:**

1.  Перейдите в Настройки
2.  Нажмите "Logout", чтобы очистить старые учетные данные
3.  Повторите шаги из раздела [Получение учетных данных API](#getting-your-api-credentials)

### Синхронизация не работает

**Проблема:** Кнопка синхронизации не реагирует или синхронизация завершается с ошибкой.

**Решения:**

1.  Проверьте подключение к интернету
2.  Убедитесь, что ваши учетные данные API верны (Настройки > Logout и введите заново)
3.  Проверьте, доступен ли сайт Rule34.xxx
4.  Попробуйте сначала синхронизировать одного автора (нажмите на автора, затем кнопку "Repair")

### Посты не отображаются

**Проблема:** Вы синхронизировали, но не видите постов.

**Решения:**

1.  Убедитесь, что у автора есть посты на сайте
2.  Проверьте, не включена ли фильтрация по рейтингу (возможно, посты отфильтрованы)
3.  Попробуйте кнопку "Repair" на карточке автора (повторная синхронизация с начала)
4.  Проверьте сообщения о ходе синхронизации на наличие ошибок

### Приложение работает медленно

**Проблема:** Приложение работает вяло, особенно при большом количестве постов.

**Решения:**

1.  Очистите кеш (Настройки > Хранилище и кеш > Clear Cache)
2.  Уменьшите количество отслеживаемых авторов
3.  Используйте фильтры, чтобы уменьшить количество видимых постов
4.  Скомпактируйте базу данных (Настройки > Управление базой данных > Vacuum/Compact)

### Не удается загрузить файлы

**Проблема:** Кнопка загрузки не работает или файлы не сохраняются.

**Решения:**

1.  Проверьте, есть ли у вас права на запись в папку загрузки
2.  Убедитесь, что у вас достаточно места на диске
3.  Попробуйте выбрать другое место для загрузки
4.  Проверьте, не блокирует ли ваш антивирус запись файлов

### Ошибки базы данных

**Проблема:** Приложение показывает ошибки базы данных или не запускается.

**Решения:**

1.  **Сначала создайте резервную копию** (если приложение все еще открывается)
2.  Попробуйте восстановиться из недавней резервной копии
3.  Если это не сработает, возможно, вам потребуется удалить базу данных и начать заново:
    -   Закройте приложение
    -   Удалите файл базы данных (расположение указано в Настройках)
    -   Перезапустите приложение (оно создаст новую базу данных)
    -   Повторно введите свои учетные данные и добавьте авторов

**Расположение базы данных:**

Приложение использует `app.getPath("userData")` из Electron для определения расположения базы данных. Это обеспечивает совместимость с различными методами установки и операционными системами.

**Стандартные расположения (управляемые Electron):**
-   **Windows:** `%APPDATA%/RuleDesk/metadata.db` (обычно `C:\Users\ВашеИмя\AppData\Roaming\RuleDesk\`)
-   **macOS:** `~/Library/Application Support/RuleDesk/metadata.db`
-   **Linux:** `~/.config/RuleDesk/metadata.db`

**Портативный режим:**
-   **Portable:** `data/metadata.db` (рядом с исполняемым файлом, если запущен из портативного исполняемого файла)

**Примечание:** Точный путь может отличаться. Приложение автоматически определяет правильное расположение с помощью встроенного управления путями Electron. Вам не нужно вручную находить файл базы данных, если только вы не занимаетесь устранением неполадок.

### Советы по производительности

-   **Скомпактируйте базу данных** — Оптимизирует размер файла базы данных
