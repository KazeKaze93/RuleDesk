## Установка

### Windows

1.  Загрузите установщик со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Запустите установщик (файл `.exe`)
3.  Следуйте инструкциям мастера установки
4.  RuleDesk будет установлен в папку Programs

**Портативная версия (опционально):**

Если вы предпочитаете портативную версию, не требующую установки:

1.  Загрузите портативный файл `.exe`
2.  Извлеките его в любую папку
3.  Запустите `RuleDesk.exe` напрямую
4.  Ваши данные будут храниться в папке `data/` рядом с исполняемым файлом

### macOS

1.  Загрузите файл `.dmg` со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Откройте файл `.dmg`
3.  Перетащите RuleDesk в папку Applications
4.  Откройте RuleDesk из папки Applications (возможно, потребуется разрешить его в System Preferences > Security)

### Linux

1.  Загрузите файл `.AppImage` со [страницы релизов](https://github.com/KazeKaze93/ruledesk/releases)
2.  Сделайте его исполняемым: `chmod +x RuleDesk-*.AppImage`
3.  Запустите его: `./RuleDesk-*.AppImage`

## Первый запуск

При первом открытии RuleDesk вы увидите экран **Onboarding**. Здесь вам нужно будет ввести свои учетные данные API.

### Что такое учетные данные API?

RuleDesk требуются учетные данные вашей учетной записи Rule34.xxx для получения постов. Эти учетные данные:

-   **User ID** - Идентификационный номер вашей учетной записи
-   **API Key** - Специальный ключ, позволяющий RuleDesk получить доступ к API

**Не беспокойтесь** — эти учетные данные зашифрованы и надежно хранятся на вашем компьютере. Они никогда не отправляются никуда, кроме API Rule34.xxx.

---

## Получение учетных данных API

1.  **Откройте веб-браузер** и перейдите по адресу:

    ```
    https://rule34.xxx/index.php?page=account&s=options
    ```

2.  **Войдите** в свою учетную запись Rule34.xxx (если вы еще не вошли)

3.  **Прокрутите вниз** до раздела "API Access"

4.  **Скопируйте свои учетные данные:**

    -   **User ID** - Число рядом с "User ID"
    -   **API Key** - Длинная строка рядом с "API Key"

5.  **Вставьте их в RuleDesk:**

    -   Вы можете вставить всю URL-ссылку со страницы учетной записи, и RuleDesk автоматически извлечет учетные данные
    -   Или введите их вручную в поля

6.  **Нажмите "Save and Login"**

Вот и все! Теперь вы готовы использовать RuleDesk.

## Основные операции

### Добавление отслеживаемых художников

**Что такое "отслеживание"?** Отслеживание означает, что RuleDesk будет автоматически проверять наличие новых постов от определенных художников или Tag.

**Как добавить художника:**

1.  Нажмите кнопку **"Tracked"** на боковой панели (левая часть экрана)

2.  Нажмите кнопку **"Add Source"** (в правом верхнем углу, со значком +)

3.  Заполните форму:

    -   **Name** - Удобное имя для этого художника (например, "Мой любимый художник")
    -   **Tag** - Tag или имя пользователя для отслеживания (например, "artist_name" или "tag_name")
    -   **Type** - Выберите:
        -   **Tag** - Отслеживать посты с этим Tag
        -   **Uploader** - Отслеживать посты, загруженные этим пользователем
        -   **Query** - Отслеживать посты, соответствующие пользовательскому запросу
    -   **Source** - Выберите, какой сайт использовать (Rule34.xxx или Gelbooru)

4.  Нажмите **"Add"**

Художник появится в вашем списке отслеживаемых!

**Совет:** Вы можете использовать поле поиска для нахождения Tag. Введите несколько букв, и RuleDesk предложит соответствующие Tag.

### Синхронизация постов

**Что такое синхронизация?** Это процесс, при котором RuleDesk загружает новые посты с веб-сайта и сохраняет их в вашу локальную базу данных.

**Как синхронизировать:**

1.  Нажмите кнопку **"Sync All"** на боковой панели (вверху боковой панели, со значком обновления)

2.  Дождитесь завершения синхронизации. Вы увидите сообщения о ходе выполнения, такие как:

    -   "Синхронизация artist_name..."
    -   "Найдено 15 новых постов"
    -   "Синхронизация завершена!"

3.  Синхронизация выполняется в фоновом режиме, поэтому вы можете продолжать использовать приложение во время ее выполнения

**Автоматическая синхронизация:**

Вы можете включить автоматическую синхронизацию в Settings:

-   **Auto-sync on startup** - Синхронизация при запуске приложения
-   **Periodic sync** - Синхронизация каждые X минут во время работы приложения

**Как включить:**

1.  Перейдите в **Settings** (боковая панель)
2.  Прокрутите до **Sync Settings**
3.  Включите **"Auto-sync on Startup"**
4.  Установите **"Periodic Sync Interval"** (например, 30 минут)

### Просмотр постов

**Чтобы просмотреть посты от отслеживаемого художника:**

1.  Перейдите на страницу **"Tracked"**
2.  Нажмите на карточку художника
3.  Вы увидите галерею всех его постов

**В галерее:**

-   **Прокрутите вниз**, чтобы увидеть больше постов (они загружаются автоматически)
-   **Нажмите на пост**, чтобы открыть его в полноэкранном режиме просмотра
-   **Используйте клавиши со стрелками** (← →) для навигации между постами
-   **Нажмите Esc**, чтобы закрыть просмотрщик

**Информация о посте:**

Каждая карточка поста показывает:

-   Изображение предварительного просмотра
-   Значок рейтинга (Safe/Questionable/Explicit)
-   Значок типа медиа (изображение или видео)
-   Индикатор просмотра (если вы его уже видели)
-   Звезда избранного (если вы добавили его в избранное)

## Функции

### Поиск

**Поиск художников локально:**

1.  Перейдите на страницу **"Tracked"**
2.  Используйте поле поиска вверху
3.  Введите имя художника или Tag
4.  Результаты появляются по мере ввода

**Удаленный поиск по Tag:**

1.  При добавлении художника начните вводить текст в поле "Tag"
2.  RuleDesk выполнит поиск в базе данных Tag веб-сайта
3.  Выберите Tag из предложений

**Поиск постов:**

1.  Перейдите на страницу **"Browse"** (когда будет реализовано)
2.  Используйте строку поиска в верхней панели
3.  Введите Tag или ключевые слова
4.  Результаты будут фильтроваться автоматически

### Избранное

**Что такое избранное?** Отмечайте посты, которые вам нравятся, чтобы легко находить их позже.

**Как добавить пост в избранное:**

1.  Откройте пост в просмотрщике (нажмите на него)
2.  Нажмите **значок звезды** (⭐) в элементах управления просмотрщика
3.  Или нажмите **F** на клавиатуре

**Просмотр избранного:**

1.  Нажмите **"Favorites"** на боковой панели
2.  Вы увидите все посты, добавленные в избранное

**Удалить из избранного:**

1.  Откройте пост
2.  Нажмите значок звезды еще раз (или нажмите F)
3.  Звезда станет серой (удалено из избранного)

### Загрузка постов

**Загрузка одного поста:**

1.  Откройте пост в просмотрщике
2.  Нажмите кнопку **"Download Original"** (значок загрузки)
3.  Выберите, куда сохранить файл
4.  Нажмите **"Save"**

Загрузка начнется, и вы увидите индикатор прогресса.

**После загрузки:**

-   Нажмите **"Open in Folder"**, чтобы увидеть загруженный файл
-   Файл будет сохранен под своим оригинальным именем

**Примечание:** Загрузки сохраняются в выбранное вами место, а не в кеш приложения.

### Фильтры и сортировка

**Фильтрация постов по рейтингу:**

1.  В любом режиме галереи посмотрите на верхнюю панель
2.  Нажмите кнопку **"Filters"**
3.  Выберите рейтинг: **Safe**, **Questionable** или **Explicit**
4.  Галерея обновится, чтобы показывать только посты с этим рейтингом

**Фильтрация по типу медиа:**

1.  Нажмите **"Filters"** в верхней панели
2.  Выберите **"Images"** или **"Videos"**
3.  Галерея обновляется автоматически

**Сортировка постов:**

1.  Нажмите раскрывающийся список **"Sort"** в верхней панели
2.  Выберите:
    -   **Date Added (Newest)** - Сначала недавно синхронизированные посты
    -   **Date Added (Oldest)** - Сначала самые старые синхронизированные посты
    -   **Posted Date** - Когда пост был изначально опубликован
    -   **Rating** - Группировка по рейтингу

**Фильтрация по Tag:**

1.  Откройте пост в просмотрщике
2.  Нажмите кнопку **"Tags"** (или нажмите **T**), чтобы открыть панель Tag
3.  Нажмите на любой Tag, чтобы добавить его как фильтр
4.  Щелкните правой кнопкой мыши (или удерживайте клавишу-модификатор), чтобы исключить Tag
5.  Галерея обновится, чтобы показывать только посты, соответствующие вашим фильтрам

**Сброс фильтров:**

-   Нажмите кнопку **"Clear Filters"** в верхней панели
-   Или вручную удалите фильтры из панели Tag

### Пометка постов как просмотренных

**Зачем помечать посты как просмотренные?** Это помогает вам отслеживать то, что вы уже видели, чтобы вы могли сосредоточиться на новом контенте.

**Пометить пост как просмотренный:**

1.  Откройте пост в просмотрщике
2.  Нажмите **V** на клавиатуре
3.  Или нажмите кнопку **"Mark as Viewed"**

**Визуальный индикатор:**

-   Просмотренные посты отображают небольшой значок/индикатор на карточке поста
-   Это помогает вам быстро увидеть новое

**Пометить все как просмотренные:**

-   Эта функция запланирована для будущих релизов

## Навигация

RuleDesk имеет **боковую панель** слева с основными разделами:

### Разделы боковой панели

-   **Updates** - Просмотр всех новых постов от отслеживаемых художников (запланировано)
-   **Browse** - Просмотр всех кэшированных постов с фильтрами (запланировано)
-   **Favorites** - Ваша коллекция избранных постов
-   **Tracked** - Управление отслеживаемыми художниками и Tag
-   **Settings** - Конфигурация и предпочтения приложения

### Верхняя панель

**Верхняя панель** появляется на страницах с контентом и предоставляет:

-   **Search box** - Поиск художников, Tag или постов
-   **Filters button** - Открытие панели фильтров
-   **Sort dropdown** - Изменение порядка сортировки
-   **View toggle** - Переключение между режимами просмотра (сетка/список)
-   **Sync status** - Просмотр времени последней синхронизации и прогресса

### Сочетания клавиш

**В просмотрщике:**

-   **Esc** - Закрыть просмотрщик
-   **← / →** - Предыдущий/Следующий пост
-   **F** - Переключить избранное
-   **V** - Пометить как просмотренный
-   **T** - Переключить панель Tag

**Глобальные:**

-   **Ctrl/Cmd + S** - Синхронизировать все (запланировано)
-   **Ctrl/Cmd + F** - Фокусировка поиска (запланировано)

## Настройки

Доступ к Settings осуществляется нажатием **"Settings"** на боковой панели.

### Настройки синхронизации

-   **Auto-sync on Startup** - Автоматическая синхронизация при запуске приложения
-   **Periodic Sync Interval** - Как часто проверять наличие новых постов (например, каждые 30 минут)
-   **Rate Limiting** - Настройка задержек между запросами API (расширенные)

### Хранилище и кеш

-   **Cache Limit** - Максимальный размер для кэшированных изображений предварительного просмотра
-   **Clear Cache** - Удалить все кэшированные изображения (освобождает место на диске)
-   **Storage Usage** - Просмотр объема используемого приложением места

### Безопасность

-   **API Key Storage** - Ваши учетные данные зашифрованы и надежно хранятся
-   **Logout** - Очистить учетные данные и вернуться к экрану onboarding

### Управление базой данных

-   **Create Backup** - Создать резервную копию вашей базы данных (рекомендуется перед серьезными изменениями)
-   **Restore Backup** - Восстановить из предыдущей резервной копии
-   **Integrity Check** - Проверить базу данных на отсутствие повреждений
-   **Vacuum/Compact** - Оптимизировать размер файла базы данных

**Как создать резервную копию:**

1.  Перейдите в **Settings**
2.  Прокрутите до **Database Management**
3.  Нажмите **"Create Backup"**
4.  Будет создан файл резервной копии с отметкой времени
5.  Местоположение файла откроется автоматически

**Как восстановить резервную копию:**

1.  Перейдите в **Settings** > **Database Management**
2.  Нажмите **"Restore Backup"**
3.  Выберите файл резервной копии
4.  Подтвердите восстановление
5.  Приложение перезапустится автоматически

## Устранение неполадок

### Ошибка "No API credentials"

**Проблема:** Приложение сообщает, что вам нужно ввести учетные данные API.

**Решение:**

1.  Перейдите в Settings
2.  Нажмите "Logout", чтобы удалить старые учетные данные
3.  Повторите шаги из раздела [Получение учетных данных API](#getting-your-api-credentials)

### Синхронизация не работает

**Проблема:** Кнопка синхронизации не работает или синхронизация завершается с ошибкой.

**Решения:**

1.  Проверьте ваше интернет-соединение
2.  Убедитесь, что ваши учетные данные API верны (Settings > Logout и введите заново)
3.  Проверьте, доступен ли веб-сайт Rule34.xxx
4.  Попробуйте сначала синхронизировать одного художника (нажмите на художника, затем кнопку "Repair")

### Посты не отображаются

**Проблема:** Вы синхронизировали, но не видите никаких постов.

**Решения:**

1.  Убедитесь, что у художника есть посты на веб-сайте
2.  Проверьте, не используете ли вы фильтрацию по рейтингу (возможно, посты отфильтрованы)
3.  Попробуйте кнопку "Repair" на карточке художника (повторная синхронизация с начала)
4.  Проверьте сообщения о ходе синхронизации на наличие ошибок

### Приложение работает медленно

**Проблема:** Приложение работает вяло, особенно при большом количестве постов.

**Решения:**

1.  Очистите кеш (Settings > Storage & Cache > Clear Cache)
2.  Уменьшите количество отслеживаемых художников
3.  Используйте фильтры, чтобы уменьшить количество видимых постов
4.  Скомпактируйте базу данных (Settings > Database Management > Vacuum/Compact)

### Не удается загрузить файлы

**Проблема:** Кнопка загрузки не работает или файлы не сохраняются.

**Решения:**

1.  Проверьте, есть ли у вас разрешения на запись в папку для загрузок
2.  Убедитесь, что у вас достаточно свободного места на диске
3.  Попробуйте выбрать другое место для загрузки
4.  Проверьте, не блокирует ли ваш антивирус запись файлов

### Ошибки базы данных

**Проблема:** Приложение показывает ошибки базы данных или не запускается.

**Решения:**

1.  **Сначала создайте резервную копию** (если приложение еще открывается)
2.  Попробуйте восстановить из недавней резервной копии
3.  Если это не сработает, возможно, вам потребуется удалить базу данных и начать заново:
    -   Закройте приложение
    -   Удалите файл базы данных (местоположение указано в Settings)
    -   Перезапустите приложение (оно создаст новую базу данных)
    -   Повторно введите свои учетные данные и добавьте художников

**Расположение базы данных:**

Приложение использует `app.getPath("userData")` Electron для определения расположения базы данных. Это обеспечивает совместимость с различными методами установки и операционными системами.

**Стандартные расположения (управляются Electron):**
-   **Windows:** `%APPDATA%/RuleDesk/metadata.db` (обычно `C:\Users\YourName\AppData\Roaming\RuleDesk\`)
-   **macOS:** `~/Library/Application Support/RuleDesk/metadata.db`
-   **Linux:** `~/.config/RuleDesk/metadata.db`

**Портативный режим:**
-   **Portable:** `data/metadata.db` (рядом с исполняемым файлом, если запускается из портативного исполняемого файла)

**Примечание:** Точный путь может отличаться. Приложение автоматически определяет правильное расположение с помощью встроенного управления путями Electron. Вам не нужно вручную находить файл базы данных, за исключением случаев устранения неполадок.

## Советы и хитрости

### Организация вашей коллекции

-   **Используйте избранное**, чтобы отмечать посты, которые вы хотите сохранить
-   **Помечайте посты как просмотренные**, чтобы отслеживать то, что вы видели
-   **Используйте фильтры**, чтобы быстро находить нужный контент
-   **Регулярно создавайте резервные копии**, чтобы защитить свои данные

### Советы по производительности

-   **Ограничьте количество отслеживаемых художников** - Больше художников = более длительное время синхронизации
-   **Используйте фильтры** - Фильтрация уменьшает количество постов для отображения
-   **Периодически очищайте кеш** - Освобождает место на диске
-   **Скомпактируйте базу данных** - Поддерживает оптимальный размер файла базы данных

### Предложения по рабочему процессу

1.  **Начните с малого** - Сначала добавьте нескольких художников, чтобы освоиться
2.  **Синхронизируйте регулярно** - Настройте автоматическую синхронизацию для удобства
3.  **Используйте избранное** - Отмечайте понравившиеся посты во время просмотра
4.  **Эффективно фильтруйте** - Используйте фильтры по рейтингу и Tag, чтобы найти то, что вам нужно
5.  **Часто делайте резервные копии** - Создавайте резервные копии перед серьезными изменениями
